
NGSL(New General Service List) 1.2 是 NGSL 的最新版本。它是一份包含 2809 个单词的第二语言学习者通用英语及日常生活中最重要的词汇列表。虽然这只占英语母语者所知词汇量的不到 1%，但平均覆盖了大多数通用英语文本的 92%，在其他情境中覆盖率更高（如《哈利·波特》93% 覆盖率，TOEIC 考试覆盖率 94%，许多电视节目如《老友记》覆盖率 95%）。
